## Playbook wording

The baseline recorded the supplied environment, C# 15 facts, union scope, mutation and entry definitions,
and test convention changes. The packages made these further clarifications.

- **Reached from a parameter, reached from a field, mutating call.** B explains where a path crosses
  shared storage, including span and memory views and writable `ref` results. It distinguishes writes
  through references still carried by a copy from replacing the copy's own slots or rebinding a ref field.
- **Entry rule.** C calls out aliases, foreach elements, pattern bindings and using initializers as anchor
  sources. All alternatives of a conditional, coalescing or switch assignment need an anchor.
- **C# 15 facts for closed classes.** D records CS9382 for direct subtypes in a different assembly,
  as observed in the compiler test.
- **FP0403.** D says `direct subtype` explicitly so the rule's relationship to an indirect subtype
  of a referenced case is clear.
